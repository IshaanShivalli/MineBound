Game Development Specification: MineBoundContextMineBound is a 2D top-down hybrid game created using Lua and LÖVE 11.5. The game combines MOBA-style hero combat with real-time tile-grid building and resource management. Players control a hero, mine resources, construct defensive structures, and fight to destroy the enemy core while protecting their own.Project Folder StructurePlaintextMineBound/

TaskWrite the initial codebase foundation for MineBound in Lua for LÖVE 11.5 using the structure above.Requirements:Configuration (conf.lua): Set window dimensions to $1280 \times 720$, enable vsync, and title the window "MineBound".State Management (src/StateMachine.lua): Implement a state machine class that handles transitioning between different game states (change, update, render).Core Entry Point (main.lua):Initialize push for virtual resolution rendering ($640 \times 360$).Instanciate the StateMachine with at least three required states: TitleState, PlayState, and GameOverState.Bind input keys (Escape to quit/pause, Enter to transition states).PlayState Core Loop (src/states/PlayState.lua):Render a simple 2D tile grid representing the arena.Draw a controllable player square (Hero) with basic 4-directional movement (WASD / Arrow keys).Include a toggle key (e.g., Space or Left Click) to place or destroy a block on the grid at the player's position.Track a simple win/loss trigger condition (e.g., health reaching $0$ or destroying a target structure) that pushes the game to GameOverState.
